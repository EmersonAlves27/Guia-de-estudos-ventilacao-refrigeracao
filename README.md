# Guia-de-estudos-ventilação-refrigeração

Este guia foi utilizado para aprimorar e facilitar o aprendizado envolvendo informações de sistemas de refrigeração e ventilação ao qual podem ser usadas para a elaboração de trabalhos e conhecimentos gerais e bem estruturados a respeito do tema.

As fontes utilizadas para alimentar a IA pelo NotebookLM, foram fontes de artigos diversos de refrigeração e carga térmica ao qual podemos identificar cálculos e embasar informações essenciais de conhecimento a respeito do assunto. Dentre essas fontes estão livros de Termodinâmica, para conhecimento teórico dos ciclos, formação da ASHRAE ao qual é a base de cálculo e tabelas que envolvem fluidos e refrigeração, Trabalhos de conclusão de curso publicados ao qual foram utilizados diferentes metodologias para cálculo e dimensionamento de sistema de refrigeração, entre outros.

Para a validação do conteúdo, utilizei perguntas como "Me explique o funcionamento do ciclo de refrigeração e quais os tipos de sistemas de refrigeração nós podemos adotar?" "Quais as cargas térmicas necessárias a serem calculadas para um bom estudo e bom dimensionamento de um sistema de refrigeração?" . Pois desta forma seria possível garantir uma boa informação a respeito do que se deve ter de conhecimento básico de sistemas de refrigeração e o que deve ser levado em consideração para o bom dimensionamento de um.
